# ALX Zero Day

This repository contains training exercises and code samples from the ALX Zero Day program - an intensive software engineering bootcamp.

## Structure

- **0x03-git/** - Git version control training
  - `bash/` - Shell scripting exercises
  - `c/` - C programming examples
  - `.gitignore` - Git ignore patterns

## Getting Started

```bash
# Clone the repository
git clone git@github.com:tech-tailor/alx-zero_day.git

# Navigate to the project
cd alx-zero_day

# Try the bash exercises
./0x03-git/bash/alx
./0x03-git/bash/school
```

## Contents

| Directory | Description |
|-----------|-------------|
| `bash/alx` | ALX School demo script |
| `bash/school` | School message script |
| `bash/98` | Placeholder file |
| `c/c_is_fun.c` | C programming example |

## Requirements

- Git
- Bash (Linux/macOS)
- C compiler (for C exercises)
